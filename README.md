# Hi, I'm Navaneesh 👋

I'm a student developer who enjoys turning ideas into useful web apps and AI-assisted tools. I work across interfaces, APIs, and automation, and I like projects that solve a problem someone actually has.

**Explore my work:** [HORA Staycation](https://github.com/n335h-max/horastaycation) · [whatsnq](https://github.com/n335h-max/whatsnq) · [TanamPintar](https://github.com/n335h-max/TanamPintar_K12)

## Selected work

### 🏡 [HORA Staycation](https://github.com/n335h-max/horastaycation)

A staycation booking web app with guest booking flows and a management portal. Built with React, Supabase, and Stripe. **[View the live site ↗](https://horastaycation.vercel.app)**

### 💬 [whatsnq](https://github.com/n335h-max/whatsnq)

A WhatsApp AI agent builder with configurable business knowledge, conversation context, and a React dashboard. Built with Node.js, Express, and AI provider integrations.

### 🌱 [TanamPintar](https://github.com/n335h-max/TanamPintar_K12)

A crop planning MVP that brings together market prices, climate conditions, and oversupply risk to suggest what to plant. Built with a React and TypeScript frontend and a Python FastAPI backend.

## Tools I've used

- **Frontend:** React · TypeScript · JavaScript · Tailwind CSS
- **Backend & data:** Node.js · Express · Python · FastAPI · Supabase · SQLite
- **Integrations:** WhatsApp · Telegram · AI APIs · Stripe
